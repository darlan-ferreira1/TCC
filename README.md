# Exposição Virtual Interativa de Física

Trabalho de Conclusão de Curso (TCC) em Ciência da Computação, UFC Campus Quixadá.

- **Autor:** Darlan Oliveira Ferreira

Uma exposição 3D no navegador, com salas de Física (Mecânica) do ensino médio. O estudante anda em primeira pessoa e resolve exercícios dentro das salas.

**Acesse:** https://darlan-ferreira1.github.io/TCC/

## Stack

- [React](https://react.dev/) 19 + [TypeScript](https://www.typescriptlang.org/)
- [Three.js](https://threejs.org/) (cena 3D)
- [Vite](https://vite.dev/) (desenvolvimento e build)
- GitHub Pages (deploy)

## Como rodar

Pré-requisito: [Node.js](https://nodejs.org/) 20 ou superior.

```bash
npm install
npm run dev
```

Depois abra http://localhost:5173/ no navegador.

### Outros comandos

| Comando | O que faz |
|---|---|
| `npm run build` | Gera a versão final em `dist/` |
| `npm run preview` | Serve a versão de `dist/` localmente |
| `npm run lint` | Verifica o código com o ESLint |
